Questions

Good to know.

Is Summon really free?

Yes. It’s free and open source under the MIT licence. There’s no trial, no ads, and nothing to sign up for.

Windows says “Windows protected your PC”. Is it safe?

Summon is brand new and isn’t code-signed yet, so Microsoft Defender SmartScreen hasn’t seen enough downloads to recognise it. Click More info → Run anyway to install. If Smart App Control is switched on, Windows may block unsigned apps entirely until a signed release is available. All of the source code is on GitHub for anyone to read.

Alt + Space doesn’t open Summon.

Another app (often PowerToys Run) already uses that shortcut. Summon will tell you when it can’t claim it — right-click the tray icon, open Settings, and record any shortcut you like.

Which versions of Windows does it support?

64-bit Windows 10 and Windows 11.

Does it slow my PC down?

Summon waits quietly in the system tray and only scans your apps when it starts and every so often after that. It checks the clipboard for new text a couple of times a second, which is a tiny amount of work. You can turn clipboard history off in Settings.

How do I uninstall it?

Open Windows Settings → Apps → Installed apps, find Summon and choose Uninstall. To remove your clipboard history too, delete the %APPDATA%\Summon folder.
